# Build, Compile, and Run Instructions

## 1. Build and Compile

### Using g++ (Linux / macOS / WSL)
```bash
g++ -std=c++17 -pthread main.cpp -o lfg
```
## 2. Run the Program
```bash
./lfg
```
## 3. Input Parameters

When the program starts, enter the following when prompted:
Number of dungeon instances (n):
Number of TANKS (t):
Number of HEALERS (h):
Number of DPS (d):
Minimum dungeon time t1 (seconds):
Maximum dungeon time t2 (seconds):
